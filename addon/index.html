Warvideo Companion

Warvideo Companion is a tiny World of Warcraft add-on. It does exactly one thing: it keeps the game's advanced combat logging turned on so the Warvideo Mac app can read the combat log and automatically detect dungeons, raids, Mythic+ runs, and boss fights. No orb, no overlay, no settings.

Manual recording in Warvideo works without this add-on. The add-on is only needed for automatic recording.

Download

Latest version: 1.4.11 — compatible with World of Warcraft Retail.

Download WarvideoCompanion.zip

Install

  1. Download and unzip WarvideoCompanion.zip.
  2. Copy the WarvideoCompanion folder into your WoW add-ons folder:
    World of Warcraft/_retail_/Interface/AddOns/
  3. In game, type /reload (or restart WoW). You'll see "Combat logging enabled — automatic recording is ready." in chat.
  4. Open Warvideo on your Mac — automatic recording is now active.

The add-on is open and minimal: it only calls the game's standard LoggingCombat API and sets the advancedCombatLogging option. It stores nothing and sends nothing anywhere.
